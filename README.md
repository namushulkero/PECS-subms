# Random Number Generation – PECS Lab

This project is done as part of **Performance Evaluation of Computer Systems (PECS)** course.

It implements a simulator that generates random numbers following multiple probability distributions and visualizes them using histograms.

---

## Objectives

- Generate random numbers using different probability distributions
- Analyze how distributions behave with different sample sizes
- Visualize results using histograms
- Understand convergence toward theoretical distributions

---

## Implemented Distributions

The following distributions are implemented:

### 1. Uniform Distribution (Integer)
- Range: **[10, 30]**

### 2. Uniform Distribution (Real)
- Range: **[1.0, 3.0]**

### 3. Normal Distribution
- Mean: **0**
- Standard deviation: **0.75**

### 4. Exponential Distribution
- Parameter: **λ = 2**

### 5. Geometric Distribution
- Parameter: **p = 0.3**
